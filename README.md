## Before You Start

### Check your specs
First, press **Win + I** to open Settings, then search for "Windows specifications" — **I recommend copying that exact phrase to search with** — and check your Windows version to make sure you're on Windows 11. (If you're on Windows 10, 7, or 8, I can't guarantee your PC won't run into problems. If you still insist on trying, that's your call.) And most importantly: **make sure your PC can actually handle these beautification tools, that you have enough free disk space and memory, and that everything is running in good shape.**

### Get yourself an accelerator
**If you already have something that accelerates GitHub, or you can get on GitHub smoothly anytime, skip this section (consider it me just being over-cautious.)**

First, go [download the Watt Toolkit installer](https://steampp.net/) (the Lanzou Cloud mirror is recommended), then double-click the installer to set it up. Once it's installed, open the app, find **Network Acceleration** in the left sidebar, and on that page tick the checkbox to the left of **GitHub** in the list, then click **Enable**.

## Prerequisites

### Download Windhawk
**What this prerequisite enables:**
- Frosted glass for the taskbar
- Frosted glass for File Explorer
- Frosted glass for Settings
- Taskbar dock animations
- Frosted glass for the Start menu

First, go [download the Windhawk installer](https://windhawk.net/). Click **Downloads** on the official site to grab the installer, then double-click it to install Windhawk. Pick your language and follow the prompts.

### Download Winstep Nexus
**What this prerequisite enables:**
- Desktop dock

First, go [download the Winstep Nexus installer](https://apsgocn.lanzout.com/iNekQ49hcofc). Click **Download** to get the compressed archive, extract it, and follow the prompts to install.

### Download Wallpaper Engine
**What this prerequisite enables:**
- Wallpapers

If you have no idea how to use Steam, watch [this video](https://www.bilibili.com/video/BV1giQJYrEK6/?) first. Then spend a little money to buy **Wallpaper Engine** on the store, and you're all set.
